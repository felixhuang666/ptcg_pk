# RPG Quest Design

## 1. Overview
The RPG Quest system allows creators to group multiple scenes into a cohesive narrative or gameplay sequence. It serves as the top-level container for scenes and dictates the player's entry point.

## 2. Quest Structure
A Quest contains metadata, a list of scenes, and specific quest entities (like the starting scene).

### 2.1 Table Schema
```sql
create table public.game_quest (
  id integer generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  name text not null,
  scene_list jsonb null,
  quest_entities jsonb null,
  constraint game_quest_pkey primary key (id)
) TABLESPACE pg_default;
```

### 2.2 scene_list
The `scene_list` is a JSONB array of scene IDs that belong to the quest.

```json
[
  "scene_1",
  "scene_2",
  "scene_3"
]
```

### 2.3 quest_entities
The `quest_entities` JSONB structure holds quest-specific configuration, primarily the `default_scene_id` which is the entry point for the player.

```json
{
  "default_scene_id": "scene_1"
}
```

## 3. Backend API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/quests` | List all quests |
| GET | `/api/quest/{id}` | Get quest by ID |
| POST | `/api/quest` | Create new quest |
| PUT | `/api/quest/{id}` | Update quest |
| DELETE | `/api/quest/{id}` | Delete quest |

## 4. UI Design

- **Quest Editor**: A React component (`QuestEditor.tsx`) for managing quests.
  - View all quests.
  - Create, rename, delete quests.
  - Add/remove scenes from a quest.
  - Set the default scene.
  - Save to DB or local assets (`/api/save_local`).
- **RPG Mode Header**: A dropdown in the `RpgMode` component to select quests, which automatically loads the `default_scene_id`.
